# Sheet Studio 使用手册

[返回项目首页](../README.md) · [下载安装包](https://github.com/didongji91/sheet-studio/releases/latest) · [更新记录](../CHANGELOG.md)

在 VS Code 内直接查看、编辑、检索 Excel / CSV，打开 SQLite 数据库文件，或连接 PostgreSQL、MySQL、MariaDB、SQL Server。提供数据网格、SQL 编辑器、表结构查看、事务和数据导入导出，适用于日常数据维护、配置表和数据库开发。文件处理在本地完成，服务器连接直接访问配置的数据库，无需 Sheet Studio 账号。

## 安装

从 [Releases](https://github.com/didongji91/sheet-studio/releases/latest) 下载 `sheet-studio-0.2.1.vsix`。在 VS Code 扩展面板的 `…` 菜单中选择 **从 VSIX 安装…**，选择下载的安装包。也可以执行：

```powershell
code --install-extension .\sheet-studio-0.2.1.vsix
```

安装后，打开支持的表格或 SQLite 文件即可进入编辑器。如果文件被其他扩展打开，右键标签页选择 **重新打开编辑器的方式… → Sheet Studio 表格编辑器 / Sheet Studio 数据库**。

## 文件格式

| 格式 | 查看/编辑 | 保存方式 |
| --- | --- | --- |
| `.xlsx` | 支持 | 普通工作簿可直接保存；有复杂对象时导出副本 |
| `.csv`、`.tsv` | 支持 | 原格式保存，保留识别出的编码、分隔符和换行方式 |
| `.xls`、`.xlsm`、`.xlsb`、`.ods` | 兼容模式 | 导出为 `.xlsx`，或将当前工作表导出为 CSV/TSV |
| `.db`、`.sqlite`、`.sqlite3`、`.db3`、`.s3db`、`.sqllite` | SQLite 3 数据库 | 应用网格修改后用 Ctrl+S 保存；也可导出数据库副本或 SQL |

CSV 自动识别 UTF-8、带 BOM 的 UTF-16 和常见 GB18030 中文内容，支持逗号、分号、Tab 等分隔符与带引号的多行字段。导入保留前导零和长编号，普通数值可参与计算，原始数字写法（例如 `1.00`）在未编辑时保留。以 `=` 开头的 CSV 字段按文本导入。

`.db` 只是扩展名，插件会核验实际的 SQLite 3 文件头。DuckDB、Access、Berkeley DB 和加密 SQLite 不会因改名为 `.db` 而变得可读。`.sqllite` 作为常见拼写也已关联，内容仍须为 SQLite。

## 数据库工作台

### 连接与导航

| 数据源 | 打开方式 | 连接能力 |
| --- | --- | --- |
| SQLite 3 | 直接打开上述文件，或新建数据库 | 本地文件编辑，无需安装驱动 |
| PostgreSQL | 命令面板 → 数据库连接管理 | 主机、端口、数据库、用户名、密码、TLS |
| MySQL / MariaDB | 命令面板 → 数据库连接管理 | 主机、端口、数据库、用户名、密码、TLS |
| SQL Server | 命令面板 → 数据库连接管理 | SQL 用户名/密码认证、端口、数据库、TLS |

- 按 schema 展示表和视图，支持名称检索与刷新。
- 查看字段类型、主键、非空、默认值、生成列、索引、外键和 DDL。
- 连接配置保存在 VS Code 扩展存储中，密码单独使用 SecretStorage；不将密码写入连接配置。
- TLS 可关闭、校验证书，或接受自签名证书。连接前可测试配置，已有配置可编辑、删除。

### 数据编辑与 SQL

- 数据按页读取，每页 50–1000 行；支持列排序、全文本列或指定列筛选、等于、IS NULL / IS NOT NULL。
- 双击或 F2 编辑基础表单元格，支持文本、数值、NULL 和十六进制 BLOB。长整数以文本承载，避免 JavaScript 安全整数范围以外的舍入。
- 更新和删除先暂存于网格，点击 **应用修改** 后整批执行；单批最多 5000 行。支持新增记录、勾选删除、复制选中单元格或勾选行，以及从当前单元格开始粘贴矩形数据。
- 更新和删除需要主键；普通 SQLite 表无主键时可使用未被遮蔽的 rowid。视图、无法识别唯一身份的记录和生成列只读。新增记录可以使用数据库默认值。
- 网格提交使用绑定参数和事务，并检查原始可比较字段；发现记录被修改、删除或不再唯一时，拒绝整批提交。BLOB、JSON、XML 等不适合直接比较的字段不参与冲突检查。
- SQL 编辑器支持方言高亮、表名/字段补全、格式化、括号匹配、SELECT 模板、执行历史和多个结果页签。按 **Ctrl+Enter** 执行选中 SQL，未选中时执行全文。
- 每次最多显示 20 个结果集，每个 SQL 结果最多保留 1000 行；超出时提示截断。数据表网格可继续翻页，SQL 结果只读，需要编辑时切换到基础表。
- SQLite 一次 SQL 执行作为一个事务，失败时整批恢复；可执行配对的外层 BEGIN / COMMIT 导入脚本。不支持附加数据库、自定义嵌套事务和 VACUUM。
- 服务器默认自动提交；在 SQL 工具栏 **开启事务 → 提交 / 回滚**。网格批次在已开启的事务中使用保存点。服务器 DDL 是否可回滚遵循数据库自身规则。
- 取消 SQLite 查询会重建工作线程，保留此前已完成的修改；服务器取消查询会关闭当前连接，未提交事务由数据库回滚，之后需要重新连接。

### 导入、导出与外观

- 向当前基础表导入 UTF-8 CSV / TSV，首行填写数据库列名；一次 1–5000 行、最多 10 MB，按事务插入。字符串由目标数据库按列类型转换，空字段作为空字符串。
- 将 **当前页 / 当前结果** 导出为 CSV、JSON、XLSX；不会把当前页导出误作整表导出。JSON 保留列名数组、NULL 和截断标记，BLOB 导出为 `0x` 十六进制文本。
- SQLite 可导出完整数据库副本或包含表、数据、索引、视图、触发器的 SQL 脚本；SQL 导出上限 32 MB，含虚拟表时应使用数据库副本。
- 拖动列标题边缘调整网格列宽；点击右上角 **外观设置** 修改行高、背景预设或自定义背景色。背景与表格编辑器共享用户偏好，独立于系统和 VS Code 主题。网格尺寸属于编辑器视图状态，不修改数据库结构。

### SQLite 保存与文件保护

SQLite 文件在内存中编辑，**应用修改 / 执行 SQL** 后还需 **Ctrl+S** 写回文件。未应用的网格修改应先提交；关闭编辑器前请应用或撤回。已应用的修改支持 VS Code 撤销/重做、另存为和热退出恢复。

每次覆盖保存前保留原文件到 `<文件名>.sheet-studio.bak`，下一次保存会更新这份备份。保存前比较磁盘文件，检测到外部修改时拒绝覆盖；可先导出内存中的数据库副本，再重新打开。打开或保存时若发现非空 `-wal` / `-journal`，需要先在原数据库程序中完成 checkpoint 并关闭连接。

默认文件上限 128 MB，查询默认超时 30 秒，可以在设置中调整。数据库、查询结果及撤销镜像需要内存，不适合用文件模式编辑数 GB 数据库或与其他进程同时写入同一文件。

当前版本覆盖 DBeaver 风格的常用浏览、编辑和 SQL 工作流，尚未达到 DBeaver 的完整功能范围。暂不提供 Oracle、DuckDB、Access、通用 JDBC、SSH 隧道、Windows 集成认证、ER 图、可视化结构设计器、跨库同步、执行计划分析和整库服务器备份。PostgreSQL / SQL Server 的表 DDL 为根据字段信息重建的参考语句，不能代替完整结构备份；MySQL / MariaDB 使用 SHOW CREATE。服务器复杂类型、时间精度和数据库专有对象仍应结合原生工具核对。

## 表格编辑能力

- 双轴虚拟滚动的表格，单元格、行、列、矩形区域选择。
- 双击或 F2 编辑；公式栏编辑；输入地址或范围跳转。
- 多单元格复制、剪切和粘贴，内部复制保留格式并调整相对公式引用。
- 撤销重做、原文件保存、另存为、VS Code 自动保存和热退出备份恢复。
- 多工作表切换、新增、重命名、复制、删除；重命名更新显式工作表引用。
- 当前工作表或整本工作簿查找替换，支持大小写、整格匹配和正则表达式。
- 工作区表格内容检索，点击搜索结果跳转到对应文件与单元格。
- 文本包含筛选，按列筛选，升降序排序并保留首行表头。
- 行列插入删除；更新常规 A1 单元格/区域公式引用。
- 向下、向右填充；相对和绝对引用处理。
- 加粗、斜体、字号、文字颜色、背景色、水平与垂直对齐、换行、数字格式。
- 合并/取消合并；合并时拒绝覆盖区域内其他非空单元格。
- 冻结首行与首列；拖动行标题下边缘、列标题右边缘实时调整行高与列宽，双击列边缘自动适配。
- 行高和列宽支持输入精确像素值，支持选区批量调整、一次撤销及 XLSX 保存。
- 常见算术、跨工作表引用和公式计算，例如 `SUM`、`AVERAGE`、`IF`、`IFERROR`、`COUNTIF`、`VLOOKUP`、`INDEX`、`MATCH` 等。具体函数由内置公式解析器决定。
- 选区计数、平均值、求和；界面缩放；独立背景颜色，支持明暗预设和自定义色值。
- 导出 XLSX 工作簿或当前工作表的 CSV/TSV 计算结果。
- 保存前检查磁盘文件是否已被其他程序修改，避免覆盖外部更新。

## 行高、列宽和背景颜色

**开始** 工具栏提供 **顶端对齐 / 垂直居中 / 底端对齐**，适用于普通单元格、多格选区和合并单元格。打开 XLSX 时读取原有垂直对齐，复制、编辑和保存后保留。未指定垂直对齐时按底端显示。大字号的行距随字号调整；自动换行的多行文字也支持垂直对齐。

拖动左侧行号的下边缘可调整行高，拖动上方列字母的右边缘可调整列宽，拖动时实时预览尺寸。双击列边缘可根据内容自动适配列宽，按 Esc 可取消正在进行的拖动。

需要精确尺寸时，在 **视图 → 行高… / 列宽…** 输入 20–1000 像素，也可从单元格或行列标题的右键菜单打开。先选中一个区域，或按住 Shift 点击首尾行号/列字母，可批量设置这些行或列；拖动选区内的行列边缘也会批量应用。每次批量调整只需撤销一次。XLSX 保存后可保留自定义行高与列宽，包括空白行列。

在 **视图 → 背景颜色** 选择浅色、深色、暖色、浅绿，或使用取色器、输入 `#RRGGBB` 后按 Enter。默认为白色，不随 VS Code 和系统主题切换，所选颜色会保存在用户设置，并应用到所有已打开的 Sheet Studio 编辑器。点击旁边的 **重置** 可恢复白色。

编辑器背景属于个人偏好，不会修改文件内容；**开始 → 填充颜色** 用于单独设置单元格的填充色。CSV/TSV 的行列尺寸只能用于当前编辑会话，需要保留到文件时请导出为 XLSX。

## 设置

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| `sheetStudio.backgroundColor` | `#ffffff` | 独立的编辑器背景色，保存到用户设置 |
| `sheetStudio.maxFileSizeMB` | `40` | 最大读取文件大小 |
| `sheetStudio.csvEncoding` | `auto` | 自动 / UTF-8 / GB18030 / UTF-16LE |
| `sheetStudio.csvDelimiter` | `auto` | 自动或指定分隔符 |
| `sheetStudio.searchFileLimit` | `100` | 工作区检索文件数上限 |
| `sheetStudio.databaseMaxFileSizeMB` | `128` | SQLite 文件模式大小上限 |
| `sheetStudio.databaseQueryTimeoutSeconds` | `30` | SQLite 查询超时，范围 1–300 秒 |

单个文件最多读取 1,000,000 个非空单元格，单次粘贴或格式操作最多 250,000 格。大工作簿在打开、公式计算或保存时仍需要完整读取到内存。当前查找面板最多列出 2,000 条匹配，工作区检索最多返回 500 条。

## 表格兼容边界

这是日常表格编辑器的首个可用版本，尚未覆盖 Excel 的全部能力。

- 不执行 VBA 宏，不提供图表编辑器、数据透视表编辑器、Power Query、协作或打印排版。
- 含图表、透视表、Excel 表格对象、条件格式、数据验证、名称或扩展对象的 XLSX 会提示兼容模式，并禁止直接覆盖。导出副本可能无法完整保留这些对象。
- XLS、XLSM、XLSB 和 ODS 导入侧重数据、公式与基础元数据，复杂样式和对象无法保证保留。
- 不支持加密工作簿、外部工作簿公式引用、结构化表格公式、动态数组溢出和全部 Excel 新函数。无法计算且文件带有缓存值的公式显示缓存，并用黄色角标提示；缓存值可能未反映本次编辑。
- 标准 A1 引用会在插删行列时更新；整列/整行公式引用、名称、图表源区域和高级对象引用尚不自动调整。排序移动行中的相对公式，其他位置指向被排序区域的公式仍按其原坐标读取。
- 剪切保留被移动公式本身的引用；其他单元格指向剪切来源的引用仍按原坐标读取。
- 含合并单元格的工作表需先取消合并再排序。首行始终作为筛选和排序表头。
- 自动换行会设置单元格格式；行高可拖动或输入尺寸调整，暂不根据内容自动增高。
- 筛选是当前视图状态，不写入工作簿的 Excel 自动筛选定义。筛选状态下粘贴按实际行号连续写入。
- CSV/TSV 不保存样式、多工作表或公式本体，导出的是当前计算值。

## 开发

开发环境使用 Node.js 24 和 npm，扩展要求 VS Code 1.96+。

```powershell
npm ci
npm run check
npm run package
```

按 F5 启动扩展开发宿主。在独立浏览器预览界面：

```powershell
npm run build
npm run dev
```

打开 `http://127.0.0.1:5173` 预览表格，`/database` 预览 SQLite 工作台，`/database?mode=manager` 预览连接管理。SQLite 预览使用实际 SQLite 引擎和内置样例数据，导出位于 `output/database-exports`；真实文件选择、CSV 文件导入、SecretStorage 和文件生命周期由 VS Code 扩展宿主提供。

```powershell
npm run test:extension
```

集成测试使用独立的用户数据和扩展目录，不修改日常 VS Code 配置。首次运行会下载测试用 VS Code；也可以通过 `SHEET_STUDIO_VSCODE` 指定本机可执行文件：

```powershell
$env:SHEET_STUDIO_VSCODE = 'C:\path\to\Code.exe'
npm run test:extension
```

数据库测试覆盖实际 SQLite 读写、事务回滚、外键、长整数/BLOB、SQL 导出重建、工作线程取消与恢复，以及各服务器方言的绑定参数、流式结果和连接失败。服务器驱动另外使用模拟客户端验证，目前尚未完成连接真实 PostgreSQL / MySQL / MariaDB / SQL Server 实例的端到端联调。

## 技术与许可

TypeScript、React、VS Code Custom Editor API。XLSX 读写采用 ExcelJS，兼容格式读取采用 SheetJS CE 0.20.3，文本解析采用 Papa Parse，公式计算采用 fast-formula-parser，数字显示采用 SSF。SQLite 使用 SQL.js / WebAssembly 工作线程，服务器驱动为 pg、mysql2 和 mssql，SQL 编辑采用 CodeMirror 6 与 sql-formatter。依赖及其许可证见 `THIRD_PARTY_NOTICES.txt`。
